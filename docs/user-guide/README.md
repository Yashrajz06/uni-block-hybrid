# User Guide

## Student Portal

### Getting Started

1. **Registration**
   - Navigate to the registration page
   - Fill in your details (email, password, student ID, department, program)
   - Submit the form
   - You will be redirected to login

2. **Login**
   - Enter your email and password
   - Click "Sign In"
   - You will be redirected to your dashboard

### Features

#### View Profile
- Access your profile from the dashboard
- View your academic information, CGPA, and enrollment details

#### Request Transcript
1. Click "Request Transcript" button
2. Your request will be submitted for approval
3. Track the status (Pending → Approved → Issued)
4. Once issued, download your transcript with QR code

#### View Certificates
- View all your issued certificates
- Download certificates with QR codes
- Share QR codes for verification

#### Grant/Revoke Access
- Grant access to verifiers to view your credentials
- Revoke access when needed
- Manage access list from your dashboard

## Faculty Portal

### Getting Started

1. **Login** with your faculty credentials
2. Access the faculty dashboard

### Features

#### Upload Grades
1. Click "Upload Grade" button
2. Fill in student ID, course details, and grade
3. Submit the grade
4. Grade is stored on blockchain

#### Upload Course Data
1. Navigate to Courses section
2. Upload course information
3. Link courses to your faculty profile

#### Approve Transcripts
1. View pending transcript requests
2. Review student information
3. Approve or reject requests
4. Approved transcripts proceed to issuance

#### View Audit Logs
- Monitor all access to student records
- Track grade uploads and modifications
- View system activity

---

## Admin Portal

### Getting Started

1. **Login** with admin credentials
2. Access the admin dashboard

### Features

#### Issue Certificates
1. Click "Issue Certificate"
2. Enter student ID and certificate details
3. Submit to issue certificate
4. Certificate is stored on blockchain with IPFS hash

#### Issue Transcripts
1. View approved transcript requests
2. Add course grades
3. Generate and issue transcript
4. Transcript is stored on blockchain with QR code

#### Manage Users
- View all users
- Activate/deactivate accounts
- Manage permissions

#### Audit Logs
- Comprehensive audit trail
- Track all system activities
- Monitor access patterns

---

## Public Verifier Portal

### Getting Started

No login required - public access

### Features

#### Verify by QR Code
1. Scan or paste QR code data
2. Click "Verify QR Code"
3. View verification result and authenticity score

#### Verify by ID
1. Enter verification ID (e.g., transcript-TRX-123456)
2. Click "Verify ID"
3. View verification result

### Verification Results

The system displays:
- **Verification Status**: Verified/Not Verified
- **Authenticity Score**: 0-100%
- **Details**:
  - Hash Match: ✓/✗
  - IPFS Valid: ✓/✗
  - Signature Valid: ✓/✗
  - Timestamp Freshness: Score

## Best Practices

### For Students
- Keep your login credentials secure
- Download and backup your credentials
- Share QR codes only with trusted verifiers
- Regularly check your transcript and certificate status

### For Faculty
- Verify student information before uploading grades
- Double-check grade entries before submission
- Review transcript requests carefully
- Monitor audit logs regularly

### For Admins
- Verify all information before issuing certificates
- Maintain accurate records
- Regularly review audit logs
- Ensure proper access controls

### For Verifiers
- Always verify credentials through the official portal
- Check authenticity scores
- Verify QR codes match the document
- Report suspicious credentials

## Troubleshooting

### Login Issues
- Verify your email and password
- Check if your account is active
- Contact administrator if locked out

### Transcript Issues
- Check request status
- Ensure all grades are uploaded
- Contact faculty if pending for long

### Certificate Issues
- Verify certificate ID
- Check if certificate is revoked
- Contact admin for assistance

### Verification Issues
- Ensure QR code is not damaged
- Verify ID format is correct
- Check network connectivity
